# PCSX2's files that PS2Native follows or compiles, for scripts/windows/try-pcsx2.ps1
# (docs/adr/0061). When PCSX2 changes one of them between the version PS2Native
# follows and a newer one, the trial says so and saves the change to read.
#
#   <path in PCSX2's tree, * for any run of characters> | <what of PS2Native follows it>
#
# The first line that fits a file is the one taken. A file that fits none is
# PCSX2's own business: PS2Native runs it as it is.
